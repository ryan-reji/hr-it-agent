
# IT Security Policy

## 1. Information Security Responsibilities

All employees are responsible for protecting company information and systems.

Employees must access company resources only for authorized business purposes.

Sharing confidential company information with unauthorized persons is prohibited.

## 2. Multi-Factor Authentication

Multi-factor authentication (MFA) is mandatory for all employees accessing corporate email, VPN, and critical internal applications.

Employees must never share authentication codes, security tokens, or MFA approval requests.

Unexpected MFA prompts must be reported to the IT security team.

## 3. VPN and Network Security

Employees working remotely must use the approved corporate VPN.

Employees must not bypass corporate network security controls.

Unsecured public Wi-Fi must not be used to access company resources without an approved secure connection.

## 4. Security Incident Reporting

Employees must immediately report suspected phishing attacks, malware infections, unauthorized access, or data leaks to the IT security team.

Security incidents should be reported through the IT helpdesk portal or the designated security incident reporting channel.

Employees must not attempt to investigate or remove sophisticated malware independently.

## 5. Data Classification

Company information is classified into Public, Internal, Confidential, and Restricted categories.

Restricted information must only be accessed by explicitly authorized personnel.

Confidential and Restricted data must not be stored on personal cloud storage services.

## 6. Software Installation

Only software approved by the IT department may be installed on company devices.

Employees must not install pirated, unlicensed, or unauthorized software.

Software installation requests must be submitted through the IT helpdesk.

## 7. Access Control

Employees must not share accounts or use another employee's credentials.

Access permissions must follow the principle of least privilege.

Employees must notify IT when they no longer require access to a system or application.
